3. Visualization

The figures visualize UE trends across our 5 states. Including: a combined line plot, a faceted line plot by region, a bar chart of mean rates, and a choice plot of month-to-month variations.

Note: This choice plot shows month-to-month volatility in regional UE rates. We remove 2020 in order to remove any distortions in the data caused by the pandemic.

4. Reflection

The most challenging parts of this data set was getting git connected to github and trying to troubleshoot the FRED API connection blocks. Using the terminal to clone, commit, and push took a few attempts before I finally got the hang of it. The most straightforward part was probably the data extraction and ggplot visualization portion of the project. All in all, I definetely feel more comfortable running git commits mid-project in comparison to when I first started.
